# Premsons Jewellers — Sample Website (Ghasi Ram theme)

Static multi-page demo built in the same maroon/gold "Ghasi Ram Jewellers"
theme (Cormorant Garamond + Inter, vanilla JS, no build step) but with all
Premsons Jewellers content:

- index.html — homepage (hero, shop-by-category, collections, hallmark
  trust banner, services, 12+One Investment Plan, reviews + feedback form)
- catalogue.html — per-collection product grid (bridal / everyday /
  bangles / diamonds) with search, filter chips and sort
- css/styles.css — shared theme (maroon + black theme toggle)
- js/catalogue-data.js — sample product data per collection
- js/app.js — theme toggle, mobile menu, chatbot widget, gold-rate ticker,
  wishlist, shared product-card renderer
- js/catalogue-overlay.js — in-page catalogue overlay (opened from the
  homepage collection cards)

WhatsApp number, address, phone numbers, reviews and product data are all
Premsons' own — pulled from the original Tailwind-based Premsons sample
site. Open index.html directly in a browser; no build step needed.
